# Mosh-Pit Simulation
Данный репозиторий содержит симуляцию коллективного поведения толпы на музыкальных концертах, а именно феномена **мошпита (mosh pit)** и его перехода в **сёркл-пит (circle pit)**. Проект был выполнен в рамках учебного курса по вычислительной физике.

## О проекте

Мошпит — это самоорганизующаяся структура, характерная для метал- или рейв-концертов, где люди хаотично и агрессивно двигаются, прыгая и сталкиваясь друг с другом. Иногда, под влиянием музыки или спонтанно, мошпит переходит в сёркл-пит, когда участники начинают бежать по кругу.

**Цели работы:**
1.  Разработать модель для симуляции мошпита.
2.  Проверить гипотезу о том, что распределение скоростей участников соответствует распределению Максвелла (газовый режим).
3.  Исследовать условия фазового перехода между режимами мошпита и сёркл-пита.

## Физическая модель

В основе симуляции лежит агентно-ориентированная модель, где каждый человек представлен упругим шариком. Агенты делятся на два типа:
*   **Активные (мошеры):** Участвуют в движении.
*   **Пассивные:** Обычные зрители, которые стараются избегать столкновений.

На каждого агента действуют следующие силы:

1.  **Сила отталкивания (при столкновении):**
    \[
    \vec{F}_{i}^{\text{repulsion}} = \begin{cases} \epsilon \left(1 - \frac{r_{ij}}{2r_0}\right)^{3/2} \hat{r}_{ij} & r_{ij} < 2r_0 \\ 0 & \text{otherwise,} \end{cases}
    \]

2.  **Сила тяги (поддержание желаемой скорости):**
    \[
    \vec{F}_{i}^{\text{propulsion}} = \mu (v_0 - v_i) \hat{v}_i
    \]

3.  **Сила флокинга (стремление двигаться как соседи):**
    \[
    \vec{F}_{i}^{\text{flocking}} = \alpha \sum_{j=0}^{N_i} \vec{v}_j / \left| \sum_{j=1}^{N_i} \vec{v}_j \right|
    \]

4.  **Случайная сила (шум):**
    \[
    \vec{F}_{i}^{\text{noise}} = \vec{\eta}_{i}
    \]

**Параметры симуляции:**
*   Общее количество зрителей: 380
*   Количество активных агентов: 114
*   Физические параметры (радиус, целевая скорость, радиус флокинга) фиксированы.
*   Варьируемые параметры: коэффициенты шума и флокинга.
*   Численное интегрирование: метод Эйлера-Маруямы.

## Результаты

В ходе работы были получены следующие результаты:

1.  **Валидация распределения Максвелла:** В газовом режиме (мошпит) распределение скоростей активных агентов хорошо аппроксимируется распределением Максвелла. Была введена эффективная температура:
    \[
    T_{\text{eff}} = \frac{1}{N} \sum_{i=1}^{N} v_i^2, \quad \rho(v) = \frac{2v}{T_{\text{eff}}} \exp\left(-\frac{v^2}{T_{\text{eff}}}\right)
    \]

2.  **Фазовая диаграмма:** Построена фазовая диаграмма, показывающая, что режим мошпита преобладает при малых коэффициентах флокинга и высокой интенсивности шума. Сёркл-пит возникает при малом шуме и высоком значении флокинга.

3.  **Метрика перехода:** Для количественной оценки перехода в режим сёркл-пита используется средний момент импульса:
    \[
    L_z = \frac{1}{N} \sum_{i=1}^{N} (x_i' \cdot v_{y,i} - y_i' \cdot v_{x,i})
    \]
